# B2：静止液滴与寄生流

**状态（2026-09-29）：XY 已启动但仍受初始化内存问题阻塞，RZ 尚未启动，均未验收。** XY 先修正全域稠密边界装配，复算仍在后续初始化产生过高内存占用，因此主动停止并保留资源记录，详见 [xy](../../../../cases/hydro_static_drop/xy/README.md)。原物理时窗、网格与精度门槛保持。历史静滴脚本结果按各自运行元数据区分路线。

## 目的、控制方程与工况

求解不可压缩两相 NS，含黏性和表面张力，无重力、电场或供排。使用实际 Hermite 曲率和正式毛细受力，评价 Laplace 压差、曲率与寄生流。

参考 [Basilisk spurious.c](https://basilisk.fr/src/test/spurious.c)，选 La=120：D=0.8、两相 ρ=1、σ=1、μ=√(D/La)=0.0816496580927726，终时为一个黏性时间 T=D²/μ=7.83836717690617。原实现为象限和 Stokes 更新；这里采用完整镜像域并保留正式 NS 中心对流，属于同一静滴平衡问题的项目实现，不宣称逐行复现。RZ 为轴对称扩展。

| 工况 | 计算域与初态 | 边界 | 平衡压差 |
| --- | --- | --- | --- |
| [XY](../../../../cases/hydro_static_drop/xy/README.md) | [−1,1]²，圆心 (0,0)，R=0.4 | 四边自由滑移 | σ/R=2.5 |
| [RZ](../../../../cases/hydro_static_drop/rz/README.md) | r∈[0,1]，z∈[−1,1]，球心 (0,0)，R=0.4 | r=0 规则轴，其余三边自由滑移 | 2σ/R=5 |

负相为滴内，正相为滴外；两相物性相同。初始速度为零，压力由首步联立方程建立，闭域采用零均值规范；不写入解析曲率或解析压差。初始输出 pressure_available=0，后续压力属于中点时刻。

## 空间与时间离散

采用完整 C1 速度、同源相/质量/动量通量、共同中点、中心对流和能量形式黏性。XY 使用 64×64 网格、64 个参数弧段；RZ 使用 32×64 网格、32 个子午弧段，均 h=1/32，动态 AMR 关闭。现行输入改用隐式式 x²+y²−R²=0 / r²+z²−R²=0，traceTolerance=1e−10；初值仍转换为同一 Hermite 曲线。物性、边界、网格、步长与终时保持，旧参数式预检快照保留，不作为隐式版本已通过的证据。

dt=0.004898979485566356，T=7.83836717690617，共 1600 步，每 40 步写场。空间比较将网格和弧段同时加倍；代表工况另将 dt 减半，不展开 La 扫描。初始几何与解析面积 πR² / 体积 4πR³/3 的偏差单列，不能与推进中的库存漂移混淆。

## 观测量与判据

使用能量、分相积分、界面轮廓和数值曲率场。评价液量漂移、几何—库存偏差、动能、表面能、曲率相对 L2 误差及寄生速度历程。曲率用弧长或 RZ 表面积加权。

压力比较取中心距离 d≤R−2h 的滴内纯相单元和 d≥R+2h 的滴外纯相单元，h 为该叶单元最大边长，按物理体积加权均值求差。纯相检查使用接受端点几何，压强仍是已解中点量；这里是固定静滴参考区，不能移用为一般移动界面的跨相压力跳跃测量。RZ 使用 P1 压力的真实旋转体积均值，不能简单把格心压力当成体积均值。

2026-09-29 已接离线诊断。场文件提供完整速度的嵌套 5×5/9×9 格内采样最大值，格心最大值另列；采样包括叶面和顶点，但不是连续全域上界，也不覆盖未写场的物理时刻。曲率误差直接积分每帧原始 Hermite 多项式：XY 用弧长，RZ 用 2πr ds；解析参考为 1/R、2/R。自适应求积的整段/两半差另列为数值估计，不从绘图折线重建曲率。诊断代码已编译，实际数据和误差仍待集中验收。

项目门槛为压差误差 <1%、Umax/√(σ/(ρref R)) <10⁻³（ρref=1），最细档曲率相对 L2 <1%，并检查最低二阶目标。这是项目判据，不是文献统一容差。速度诊断另要求 5×5→9×9 采样增量小于毛细速度的 10⁻⁴；采样差小本身不能证明连续最大值已精确捕获。需要结合空间/时间对照与保存帧历程判断，单次分析不自动宣布通过。
