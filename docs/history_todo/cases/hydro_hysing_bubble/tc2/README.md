# Hysing TC2：高密度比、强形变二维上升气泡

**状态：原工况输入已准备，未启动物理计算，未数值验收。** 用于集中考察密度比 1000 下的质量—动量一致性、强形变与欠分辨界面的处理。参考来源和整体判据见[Hysing 算例说明](../../../../../cases/hydro_hysing_bubble/README.md)。

## 物理模型与工况

二维不可压缩两相 Navier–Stokes 方程，包含重力、黏性及恒定表面张力，无电场或相变。域 [0,1]×[0,2]；圆形气泡初始圆心 (0.5,0.5)、半径 0.25，初始速度为零。上下壁无滑移，左右壁不可穿透且自由滑移；封闭域压力取体积平均参考，不设置人为出口。

| 参数 | 曲线内部气体（negative） | 外部液体（positive） |
| --- | ---: | ---: |
| 密度 ρ | 1 | 1000 |
| 动力黏度 μ | 0.1 | 10 |

表面张力 σ=1.96，重力 (0,−0.98)，终时 T=3。使用 `units code` 并保持原工况数值尺度；本例与 TC1 仅上述两相物性和表面张力不同，不增加黏度来获得稳定结果。初始时刻没有已求解压力，输出压力时刻随后取实际中点。

## 离散与观测

基础网格 16×32、Δx=Δy=1/16，初始界面 64 个 Hermite 段；固定 Δt=0.002，共 1500 步。采用完整 C1 速度、相容压力、共享相通量、中心对流和共同中点受力。未启用 AMR、重距离或人为二维分裂操作。该分辨率是否足以解析薄丝，要由集中运行与加密对照判断。

记录完整轮廓、气泡质心、平均上升速度、圆度、独立相库存及原始能量收支。分相积分输出已接代码，三组[作者参考曲线](../../../tests/reference/hysing_bubble/README.md)已固定来源。参考文献中 TC2 晚期拓扑有方法差异，因此不指定唯一破碎形状或断裂时刻；必须区分已解析形变、几何失去分辨率和显式终端事件模型。当前二维拓扑仍有未完成项，本例不能因输入已准备就被标为已交付。不得把计算停在困难出现前的短轨迹作为 T=3 结果。
