# 后续时间步效率改造方案

日期：2026-09-29。依据：[时间步推进耗时诊断报告](QUANTUM_TimeLoop_Performance_Diagnosis_20260929.md)。状态：方案已制定，尚未实施或证明性能收益。执行待办只在[流体待办 §91](QUANTUM_CCH_Hydrodynamics_TODO.md#time-loop-redesign-plan)维护。

**主线：把几何精度、一次耦合评价和非线性求解作为一个整体改造。先解决计算量为何增长，再减少每次评价的重复工作，最后让每轮求解更有效。** 不再按“优化一个函数—重跑一轮长算例”的节奏推进。

本方案继续服从[新流体离散中心思路](QUANTUM_新流体离散中心思路.md)：唯一完整 C1 速度、唯一 Hermite 几何、独立守恒库存、共同质量—动量通量、相容压力及共同中点/Picard。原生流体拓扑不因界面切割而改变。流体与界面的最终数值验收、RZ/AMR/拓扑及后续电喷雾范围保持。

## 1. 先明确要解决的三个乘数

一次时间步的主要成本可以写成

    耗时 ≈ 完整候选评价次数 × 单次评价成本 + 线性求解总成本。

第二步实际进行了 10 次完整评价；每次平均约 54.40 秒，线性阶段每轮平均约 15.75 秒。几何分片继续增多，还会把单次成本推高。因此本轮要同时降低：

1. **每步重复多少次：** 保留共同中点方程，改进耦合方向和分解更新，减少完整评价次数。
2. **每次计算多少东西：** 一份时空几何批量服务全部面矩，一份相区积分服务多个材料算子；不变的旧时层积分只做一次。
3. **需要表示多少细节：** 明确源曲线与投影的二阶精度，区分物理曲率、参数伸缩及数值短波，避免计算量被缺乏物理解释的细节驱动。

第一轮不更换 SuperLU、不接入新的求解器库、不降低 Q8 空间阶数。已有的张量求值、纯相缓存、固定基底装配、单元内部精确消元、速度历史初值、毛细迭代度量和 Anderson 加速均保留，不把它们重新包装成待实现功能。

## 2. 新证据对方案的约束

利用同一历史 V7 轨迹保存的多项式系数，离线比较了三个接受态。没有启动物理推进，也没有使用候选速度重建曲线。

| 指标 | 初始 | t=0.002 | t=0.003 |
|---|---:|---:|---:|
| 接受曲线弧段数 | 64 | 1036 | 1983 |
| 参数速度 \(a=|X_s|\) 范围 | 0.59690–0.65973 | 0.59623–0.65988 | 0.59546–0.66006 |
| 切向伸缩项占总 H² 能量 | 0.479% | 0.552% | 0.823% |
| 去除极角 0–8 阶成分后的曲率 RMS | 1.43e−4 | 1.33e−2 | 2.01e−2 |
| 同样处理后的轮廓半径 RMS | 1.94e−10 | 8.97e−9 | 8.08e−9 |

曲率中的短尺度成分在增加，位置变化却很小；整体参数伸缩范围并未明显恶化。**不能据此把“重新分配材料节点”选作首要解决办法，也不能把这些曲率成分直接认定为物理波动或数值噪声。** 表中的切向占比是总二阶导数能量的分解，并非重构误差的分解，不能用它单独解释自适应加密。极角谱只适用于这里绕原点呈星形的液滴，不是通用判据或生产滤波器。

原始系数、输入哈希、统计脚本与积分加密对照见[离线结果](../cases/module_history/output/20260929_221915_time_loop_diagnosis/curve_shape_analysis.json)，图见[曲率尺度对照](../cases/module_history/output/20260929_221915_time_loop_diagnosis/curve_shape_diagnosis.pdf)。这些历史快照与最新计时程序不同，不混作同版本性能或完整物理验收。

另一个源码层面的缺口是：输运源曲线当前按位置和一阶导数误差接受，随后重构却按二阶导数误差加密。**后端把源曲线拟合得很精确，并不能弥补源曲线本身缺乏明确的二阶精度控制。** 需要把这两个阶段的误差定义接起来。

两个后续快照中，距网格线不超过 0.05h 的区域仅占约 21%–22% 的极角测度，却集中了约 90% 的曲率谱尾能量；求积加密后仍保持这一量级。阶段 A 优先检查原生速度支撑分界附近的导数、源逼近与投影。这个相关性还不能证明具体因果，也不作为局部平滑的依据。

## 3. 几何部分：统一源曲线和投影的物理精度

### 3.1 先定位短尺度成分在哪个阶段产生

只选一份已有真实候选，比较同一速度下的“旧接受曲线 → 输运源曲线 → 自由拟合 → 库存约束后的曲线”，同时列出法向速度和毛细虚功。所需结果是一张分阶段误差表，不扩展参数扫描。

| 首先出现增长的位置 | 对应修正位置 |
|---|---|
| 输运源曲线 | 检查离散轨迹与导数的一致性，以及源曲线的二阶逼近精度 |
| 自由拟合 | 检查误差度量、空间选择及曲率在分片接缝处的变化 |
| 库存约束修正 | 检查体积可行性与几何精度是否冲突，以及约束修正的空间分布 |
| 下一轮流体响应 | 检查完整速度对毛细弱式的响应和中点迭代的高频耦合 |

这项定位是有限的设计收口工作，不另起长轨迹。若保存的数据不含所需中间曲线，只补这一次冻结候选回放；不把缺少 FV 库存的旧快照冒充完整时间步重启状态。

### 3.2 使用共同的弧长误差度量

拟采用同一参考源曲线上的弧长导数定义重构误差。令 \(e=X_h-X_*\)、\(a_*=|\partial_sX_*|\)，则

\[
D_\ell=a_*^{-1}\partial_s,\qquad
D_\ell^2e=a_*^{-2}e_{ss}-a_{*,s}a_*^{-3}e_s.
\]

重构的候选目标为

\[
J(e)=\tfrac12\int_{\Gamma_*}
\left(\ell_g^{-4}|e|^2+\ell_g^{-2}|D_\ell e|^2+|D_\ell^2e|^2\right)\,d\ell,
\qquad V_c(X_h)=V_{l,c}^{\mathrm{FV}}.
\]

这里 \(\ell_g\) 是明确定义的局部几何分辨尺度，先与叶单元尺度关联；初始 `segments` 只决定初始曲线采样，不再隐式决定动态精度。参考度量在一次重构内固定，使几何目标保持二次形式；体积约束仍使用真实几何的非线性关系。位置、切向连续性、端点及方向约束保留。这个度量减少对材料参数命名方式的依赖，但不会自动消除源曲线中已经存在的短波。

源曲线构造也使用同一二阶尺度：沿已有材料分片比较父片与细分子片的弧长二阶导数，估计源逼近误差，并复用其映射采样。跨原生速度支撑分界按单侧分片处理；不强加当前 C1 速度并不保证的全域 C2 光滑性。总几何预算明确分成“源逼近误差＋约束重构误差”，不能只控制后者。

最终还需检查实际位置、法向、曲率及毛细虚功误差，不能仅依靠这个 Sobolev 型指标。RZ 中，几何度量沿子午弧长定义，体积和受力继续使用轴对称测度；总曲率的环向项与轴极限单独保持一致，避免面积权重在轴上消失后掩盖端点误差。

新旧度量的数值门槛不能直接照抄。先用已有解析圆/球及冻结源曲线确定相同物理精度下的预算，再统一替换旧定义；原守恒与物理验收条件不放宽。若约束要求更多真实分辨率，则应增加分辨率或明确报告欠分辨，而不是裁剪段数。

### 3.3 几何空间只在明确的阶段改变

同一非线性求解内保持共同的半步/整步空间；当误差要求加密时，所有相关候选量一起更新。步末在同一几何目标和库存约束下重新选空间，才允许移除不再需要的细节。不能在迭代中独立删节点，不能用几何体积覆盖库存。

第一轮不加入曲率滤波、人工黏度或任意最高波数截断。诊断图中的去低阶分解仅用于观察，不进入算法。一般重参数化暂不作为新增主线；只有分阶段证据证明其必要时，才在同一几何映射与库存约束内处理。

## 4. 耦合评价：一份几何完成一批工作

### 4.1 明确四种数据的有效期

| 所依赖的状态 | 持有的主要数据 | 更新时机 |
|---|---|---|
| 网格与离散空间 | 基底映射、固定几何积分、Riesz 因子和约束 | 网格、边界或空间改变 |
| 已接受物理状态 | 旧几何、独立库存、旧时层材料矩与体积矩 | 接受新步或物理事件后 |
| 当前候选速度 | 半步/整步几何、相通量、当前材料、受力和动量输运 | 候选速度改变 |
| 求解近似 | 预条件分解、毛细迭代度量和历史方向 | 根据有效性与实际成本维护 |

沿用已有模块所有者，合并当前分散的复用规则。尤其将共同质量流中反复积分的 previous 时层移至接受态，将只依赖网格的 Riesz 因子提升到网格有效期；next/midpoint 必须仍对应当前候选。

### 4.2 共享时空几何，批量计算全部面矩

目前同一平面的几何图表已有共享，部分速度求值也已批量化；剩余改造是把各 Bernstein 加权液相通量的独立自适应遍历合成向量积分。一个积分节点一次获得交点、映射和速度，形成所需面矩向量；根据各分量的误差预算共同决定细分。

以 \(e_j\) 表示第 j 个面矩的误差估计，\(\tau_j\) 表示其预算，可用 `max_j(e_j/τ_j)` 决定是否继续细分，同时保留原有总误差汇总约束。不能只检查零阶体积通量，也不能用矩的正负抵消掩盖分量误差。相邻单元仍消费同一份有向通量；供排边界需要的正、负通量沿用同一积分机制。

目标是减少重复的轨迹与交点求值，而不是宣称固定获得 21 倍加速。若某一分量决定所有细分，批量积分仍可能昂贵，应从真实映射调用数和整步计时判断收益。

### 4.3 相区积分服务多个算子

在一个候选、一个时层内，由同一相区划分提供有预算说明的求积节点和必要矩，供质量、黏性、体力及体内输运消费；固定基的乘积与张量收缩复用。不同时间层和不同候选的积分不混用。

保留正权 Gram 构造、完整速度及压力补空间交叉项；RZ 有理项与轴极限继续按真实算子积分。各算子若需不同精度，由共同积分包满足实际最高要求，并记录其来源。不能为了共享而把所有积分统一加严到无关的最小容差。

本轮仍使用现有全局线性系统，不同时启动全面 matrix-free 改造。MFEM 的高阶计算设计支持利用张量和部分装配降低存储与访存，但真实 cut geometry、RZ 及预条件器需要专门设计；它是后续大规模路线参考，不是本轮直接替换方案。[MFEM 性能说明](https://mfem.org/performance/)

并行继续围绕现有面、单元任务展开。工作区由线程复用，候选失效时统一释放大型临时量。先降低工作量与内存占用，再用阶段计时确定线程数；不把 8 线程直接翻倍作为主要措施。

## 5. 非线性求解：保留原方程，更新有效的近似

完整共同中点方程仍记作 \(R(x)=A(q)x-b(q)=0\)。当前 Picard 近似冻结了几何、通量和材料的响应；已有毛细度量只覆盖部分耦合，并且在步初几何上构造。改造继续解同一个 R，不另立一套滞后材料或滞后界面力的物理方程。

第一轮把三项作为一个求解策略实现：

1. **与当前几何相符的毛细迭代度量。** 从现有离散表面能/牵引弱式的变化构造主导法向响应，并与实际中点几何一致。当前纯毛细力已经采用弱式及压力分解，不能误判为简单逐点沉积 `σκn`，再添加一套独立平滑力。度量作为迭代近似，在收敛时抵消；原毛细虚功和压力关系不变。
2. **在当前方程下选择线性初值。** 比较上一轮完整解与现有初值的实际残差，使用较好的一个解修正方程。网格/物理状态不兼容时不继承。此前仅编译的初值候选不能直接视为已验证实现，应纳入本次整体包。
3. **按收益更新预条件分解。** 记录重分解成本、每次迭代成本与残差收缩率；当继续使用旧分解的预计额外工作超过重建成本时更新，不再等达到 24 次上限。更新只改变求解近似，接受检查始终针对当前原方程。

原有速度历史预测和 Anderson 加速统一使用当前度量，不再叠加新的外层加速器。材料空间/拓扑变化时检查历史方向是否仍有意义；必要时重建度量和失效的历史。

内层可变精度暂不单独推进：此前已有多一轮外层的反例，且每轮完整评价约 54 秒。先落实上面三项并比较总评价次数；只有证明内层过求解仍占主要成本，才在同一策略内调整。最终物理残差门槛保持。

完整 Newton/Jacobian-free Newton 暂不选作主线。有限差分 Jacobian 乘积会调用昂贵残差，可能增加整步成本；要采用更完整的导数，必须同时考虑 `δA·x−δb` 中几何、共享通量、材料与受力的相容关系。PETSc 对残差、线性化与预条件器的分离可作为组织参考，不意味着需要引入其依赖或更换用户指定的物理离散。[SNES 文档](https://petsc.org/main/manual/snes/)、[预条件器更新](https://petsc.org/main/manualpages/SNES/SNESSetLagPreconditioner/)

## 6. 执行顺序：一个整体实现包，一次集中检查

| 阶段 | 实际交付 | 转入下一阶段的条件 |
|---|---|---|
| A：方法收口 | 一份候选的分阶段曲率来源分析；统一源/投影误差定义、积分预算和数据有效期 | 能解释在哪一层修正，以及哪些量可复用；不要求先跑完整标准轨迹 |
| B：集中实现 | 第 3–5 节贯通现有 Interface/Hydro；必要字典说明及旧分支清理一起完成 | 正式入口调用统一实现，编译通过；实现中只做必要的局部定位，不启动长验证 |
| C：集中检查与性能观察 | 一组针对改变结构的检查，加同一原规模下连续后续步的比较 | 守恒/相容/几何精度保持，且后续步成本有实质改善；不能只展示首步或微内核 |
| D：恢复标准验收 | B1–B4 和已有制造解/所需 RZ、AMR、拓扑接续 | 按原 README 与主计划完成数值要求，再进入无电破碎及后续带电阶段 |

第 B 阶段内部可以分步编译，但不为每个函数改动创建一个新算例、一套新报告或一轮全量回归。正式通过前只保留一条拟交付实现；旧程序作为冻结对照保存在既有证据中，不增加用户可选求解支路。

阶段 C 的集中检查覆盖实际变化：共同面通量与库存/动量一致性、完整矩阵/压力/黏性结构、源曲线和库存约束后的几何精度，以及实际 XY/RZ 共同中点接续。复用已有检查入口，不重建测试框架；局部检查通过只证明这次改造没有破坏相关结构，不替代阶段 D。

## 7. 性能与数值判断标准

**首轮工程目标：** 在原 B3 64×64、原 dt、相同线程和输出条件下，使连续后续步的主要耗时至少降低约一半，同时抑制无物理解释的分片/积分工作量增长。这是设计目标，不是已经取得或保证取得的结果；不能牺牲曲率、守恒或振荡响应来达到它。

性能窗口至少覆盖第 2–4 个接受步，首步单列。记录整步墙钟、完整评价次数、每次阶段成本、线性迭代/重分解、弧段/积分点数和峰值内存。已有最新程序仅一个完整后续步，不能据此给出多步平均加速比；若需要严格同窗对照，只补一次冻结基线，避免每项修改重复启动。后台负载保持可比，单次测量不声称统计稳定的加速倍数。

若没有包含独立库存、完整速度历史、几何和时间层的合法重启状态，就从相同原始输入做一次对照；不为此另建通用重启系统，也不从曲线体积伪造库存。性能窗口运行与原完整终时的数值验收分别标明，不能把观察结束写成算例完成。

方法判断继续使用现有标准问题：B1 检查长时形状、守恒和曲率；B2 检查 Laplace 压差与寄生流；B3 检查频率、相位、能量交换及数值阻尼；B4 检查大变形和高密度比。已有制造解、RZ 与 AMR 接续补齐相应独立能力。不能拿曲率谱尾变小当作振荡精度通过，更不能靠增黏、减小物性比或缩短终时获得通过。

若整体包收益不足，首先看完整评价次数、单次工作量及曲率短尺度响应三者哪一项未改善，再调整对应设计。只有这些问题收口后，大规模线性系统仍主导，才评估全面部分装配或新的预条件体系，不同时扩展所有方向。

## 8. 本轮范围与交付方式

本轮方案聚焦后续时间步效率及其数值原因。出口扩展、控制台美化、目录清理专项和带电接续仍按原排期后置。一般 RZ、AMR、边界与拓扑要求没有删除；本包必须保持已有接口，剩余能力仍在原模块待办中完成。

每完成一个大阶段，按“方法上改了什么—实际观察到什么—下一步解决什么”汇报，必要时给曲率和轮廓对照。结果仍放在 `cases/<case>/output/<时间戳>/`，`build` 只保存项目编译产物。方案制定与离线分析不计作数值模块完成。
