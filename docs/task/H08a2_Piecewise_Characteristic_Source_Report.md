## 缺口定位：没有真实跳跃，也产生了伪交叉导数

解析RZ源为 `u_r=0.2*a(t)*r, u_z=0.13*a(t)`，静态a=1；时变a从0.7线性到1.3。原真实B在全部实际分支的中心和四角、两个端点均已核验：最大值误差1.49e−16，J误差5.33e−15。物理r演化独立于z，故精确 `∂r_depart/∂z_arrive=0`。

uniform n8时变源、初值(0.36201,0.38721)、80步的候选交叉导数为 **2.04881538e−6**；同点同一离散映射的独立差分误差为6.56e−10。最细2:1 n16时变witness为(0.36201,0.35687)，交叉导数 **2.20785892e−6**，差分误差2.43e−10。七个失败族的witness全部补做差分，最大6.56e−10。

因此，当前证据排除了“换一套J就能修复”的解释：当前J确实微分了该离散映射，问题在事件分段后映射本身的导数精度。cell/knot事件使径向积分的步长依赖轴向初值，带来无物理来源的交叉敏感性；固定全局时间节点只解决了其中一部分。有限矩阵不证明所有二阶方法都不可能，也不证明非守恒FirstJet应被放弃。下一任务须联合设计轨迹及其事件敏感性，优先复现这些失败点。
