## 实际实现

仅修改 `CchKepConvection.h/.cpp` 两个生产文件。显式 `buildControlled` 在原最终 native KEP 上加入 `L_i=.5*chi*abs(F)*(u_i-u_j)`、`L_j=-L_i`；材料 F 只读消费原 H08/H09 owner，实际 AMR 子段分别共享。周期重复采样沿用原真实质量分配加速度。原默认 `build` 仍为中心路径，零 strength 的结果逐值保持。

传感器取两端实际 pressure one-ring 支撑并集上的 Favre 加权二次**采样投影余项**，除以同一支撑的加权标准差。常数场不触发，可允许二次场不触发；默认激活/饱和阈值0.2/0.5、平方斜坡及strength范围[0,1]均保持实施前登记。密度对比不单独触发耗散，没有 case/AMR 分支或隐式 donor。

新增耗散 `D=sum(.5*chi*abs(F)*jump²)>=0`，真实预算仍为 `kineticRate=materialKineticPower-boundaryKineticPower-D`。Pure FirstJet、B/J/characteristic、H08a时空积分和真实R/uR不变；无M_K/bubble、库存、R=0、quarter commuting或反向几何修复。本次没有修改压力、黏性或接受事务。
