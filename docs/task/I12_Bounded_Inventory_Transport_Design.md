# I12 / 保持几何的有界库存输运表示

**状态：r18 区域算子及 r19 恒定平移共享面通量已通过，见 [r18 报告](I12a11r18_Bounded_Inventory_Region_Report.md) / [r19 报告](I12a11r19_Bounded_Inventory_Sweep_Report.md)；完整时间驱动尚未切换。** 本文补充[已授权的几何—库存误差分离变更](I12_Geometry_Inventory_Accuracy_Design_Change.md)。用户允许放弃逐 cut cell 几何与库存的机器精度硬匹配；这里给出为维持库存有界性所需的明确离散表示，不修改原几何或原 M，也不增加另一份 production 界面。

## 为什么必须处理输运表示

如果直接把旧 Hermite 液相体积 V 的全部液量扫出，而原库存 M 小于 V，则库存更新留下 M−V<0。仅减弱 bubble 闭合无法解决此问题。原共享通量 roundoff 修复只处理浮点缺陷，不能扩大成一般几何误差修复。

设旧叶的 native 容量为 C，同一几何区域测得容量 Cg、液量 Vg。定义 a=M/C、v=Vg/Cg；两者严格在 [0,1]。保留指示函数 H=1(phi<0)，只为库存输运定义派生的有界相含量：

`rho_M(x)=w_l*H(x)+w_g*(1-H(x))`。

- 若 a<=v：`w_l=a/v, w_g=0`；当 a=v=0 时取 `w_l=1,w_g=0`（液区为空）。
- 若 a>v：`w_l=1, w_g=(a-v)/(1-v)`；此时 v<1，分母严格为正。

代数上 `0<=w_g<=w_l<=1`，整格平均值为 a；a=v 时恢复原几何指示。相反相交换 M↔C−M、V↔Cg−V 时，输运相含量互补。

权重不修改 Hermite scalar、normal、curvature、cut 或 first jets；它是原 M 与唯一几何的派生积分系数，不单独随时间推进。材料/受力仍只能消费规定的 geometry 与 M owner，不能把 rho_M 再提取为另一份界面。它也不是失败后改用全局一阶 donor：几何充分一致处恢复高阶几何积分，仅在原几何—库存差存在处调整相含量。

## 守恒、有界性与误差

对来源叶内任意子区域 A，库存液量为 `w_l*Vg(A)+w_g*Gg(A)`，非负且不超过 A 的容量。由于每叶修正相对 H 只有一个符号，准确积分时有

`integral_K abs(rho_M-H) = Cg*abs(a-v)`。

因此任何子区域的绝对修正不超过同一旧叶的总差额；一组不相交分区的修正不会凭空增加 L1 差额。不能由这个 L1 结论直接宣称曲率、Linf 或长时误差已收敛。

对不可压、体积保持的同一离散运动，如果目标单元的 departure region 被准确分割到旧叶，上式的非负有界积分给出有界新库存；共享扫掠面贡献只计算一次并成对使用，保持局部/全局守恒。这是后续接线的数学依据，前提仍包括覆盖完整、相同时间区间与同一 map。尚未实现的一般 rotation/vortex 时空覆盖不能由恒定平移证明代替。

浮点实现中 native C 与物理区域 Cg 使用的等价算术可能相差若干 ulp。整格表示为 `Cg*M/C`，其与原 M 的差必须仍在原 `64*epsilon*C` 预算内，并单独记录；不改变 M、不把容量误差混入几何容差。权重计算使用有界分数，避免将负库存或超过 1 的权重当作舍入修复。实际整格恢复、分割可加性、严格子区界限都要实测；求积估计不是严格误差界。

## r18 范围与后续

r18 只实现 prepared 库存区域积分。原 `HermiteGalsPhaseRegionSource` 在同一次裁剪/求积中暴露各叶贡献；新 owner 据旧 M 准备权重，再消费这些贡献。原几何 scalar 输出保持，查询同时返回原几何液量和库存液量以支持 A/B。独立几何门槛默认 1e-10，不调整库存 roundoff 常数。

r19 已将该区域积分接入唯一时空面传递，经原库存装配和 reflux 消费，84 组排空/充满、曲线、静止及 AMR 场景通过。原几何通量会越界的 48 组反例由新面量通过原界限检查；内部抵消、显式边界历史、区间切分及 coarse=sum(fine) 同时验证。该能力仍限单轴恒定平移，未证明一般运动。若其它 sweep 的求积不相容导致超出 roundoff 的界限缺陷，必须明确 FAIL，不能 clipping 或放宽门槛。
