## 数学约束

1. 使用当前 executable 实际重跑 `--crossing-probe`，保留退出 1 及两个原始拒绝；不能把它改成通过。
2. 用精确有理数独立核对平面跨面 q 扫描、dt 缩小、XY 与 RZ 轴向平移的归一化体积误差。RZ 截面面积为 `pi*(r1^2-r0^2)`，公式先除去共同 pi，避免将浮点估计当证明。
3. 区分固定初值时间细化与随 dt 改变初始跨面相位的反例族；后者只能反驳普适 CFL 保证，不能否定前者的所有收敛情形。
4. 检查受检求积的事件遗漏风险：有限时间样本一致不能认证其间不存在液相的出现/消失。解析脉冲只用于反例，不冒充已实现的 temporal operator。
5. 新提案继续保持唯一实际面通量、内部抵消、reflux、同源 first jet、独立 M 和原 bubble guard；不承诺时间积分单独解决全部 I12 失败。
