## 3. 动能比较：真实质量正确，面平均平方不足

用不含1/2的范数记 `E_cont=integral rho*|a|^2 dV=-A/2`，`E_native=sum_f M_f*a_f^2`。后者就是原对角native动能的二倍。80位独立解析面积分与分离求和重建36组范数，与保存二进制数据相对差最大7.651e-16。

对 `H(h)=1/2+h/2`，液/气相切向界面迹分别为 `-A*coth(kH)`、`+A*coth(k(1-H))`。跨相面条带的一阶缺失为

`Delta E = h*A^2/4*[rho_L*coth^2(kH)+rho_G*coth^2(k(1-H))] + O(h^2)`。

界面恰在normal dual边界，normal分量积分只有二阶误差。利用连续能量公式及 `k=2*pi`，得到

`E_native/E_cont = 1 - pi*coth(pi)*h + O(h^2)`，`pi*coth(pi)=3.153348094937`。

## 4. 原M上的Rayleigh下界及其假设

令K为原D无散且外壁normal为零的native子空间，Q为原M正交的压力消元逆算子。令 `g=sum_q W_q*cos(k*x_q)*B_q^T`，B同时用于界面normal运动与伴随弱牵引；力与g允许相差C的压力项。在K上，对任意z有

`g^T*Q*g >= (g^T*z)^2/(z^T*M*z)`。

取z为解析native面均值的原M投影。n64半格/rho=1e6，实测 `g^T*z=-3.13013828e-6`；归一化模态响应下界1.05038084，实际1.136809；精确normal迹的下界 `E_cont/E_native=1.05093991856`。36组数值均满足下界，没有以拟合频率选择权重。

若该解族的normal trace达到二阶或更高，`g^T*z=-E_cont+O(h^2*E_cont)`，则归一化模态mobility至少为 `1+pi*coth(pi)*h+O(h^2)`。所以在**真实native面均值、冻结对角M、同一准确normal端口、伴随弱力模压力**这组假设下，该模态反馈不能二阶收敛。线性毛细同模态频率的平方根也继承一阶下界。材料几何余项仍保留；不能拿线性小振幅下更高阶的材料非线性项抵消此二次动能缺陷。

这不是所有流体离散的普遍不可能性证明，也没有证明任意非伴随方法均失败。它限制的是上述明确算子族；原实际FirstJet周期及一般曲面的最终判定仍须原完整验收。它说明：若继续追求准确同源normal和伴随牵引，单独调整端口不能关闭冻结M下的一阶响应缺陷。
