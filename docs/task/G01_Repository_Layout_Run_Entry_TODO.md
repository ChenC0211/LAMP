## 固定规则

| 目录 | 唯一职责 |
| --- | --- |
| `cases/<算例>/system` | 可编辑、可复制的算例配置；不写结果、日志、程序副本 |
| `cases/<算例>/input/constant/data` | 求解必需的静态输入；README 是使用说明；验证参考归 `tests/reference`，示意图归 `docs/assets` |
| `runs/<算例>/<YYYYMMDD_HHMMSS_mmm_标识>` | 单次运行的输入快照、程序快照、日志、状态和求解器 `output` |
| `runs/checks`、`runs/baselines` | 检查和历史验收证据；不是普通算例配置来源 |
| `include` | 所有项目头文件；内部实现头放所属层/模块的 `detail` |
| `src` | C++ 实现翻译单元，保持 Core → Solvers → Modules → Apps 原依赖 |
| `build`、`bin` | CMake 中间产物/日志、可执行程序及运行 DLL |
| `tests`、`tools`、`docs` | 标准 CTest 检查、通用入口/专项分析、现行与历史文档 |

通用命令固定为 `tools\run_case.cmd <算例名称>`；只改末尾名称即可运行其他算例。嵌套算例使用 `hydro_static_drop/xy`，结果目录键使用 `hydro_static_drop__xy`。配置中途不自动改写；每次复制配置后运行，已有结果不覆盖。
