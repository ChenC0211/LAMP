# I12a15r1 / 同一积分的候选分割证书交集

见 [TODO](I12a15r1_All_Partition_Certificates_TODO.md) 与 [a15 设计](I12_Bounded_SpaceTime_Integral_Design.md)。本项不改变积分对象、任何 source 或自适应成功条件。

同一父区域 P 的四项真值 I(P) 分别属于旧父证书 B、切向二分子和 S、时间二分子和 T。两种分割都覆盖完整 P，不必互相嵌套，因此 I(P) 属于 B∩S∩T。原实现已计算 S 与 T，却只保留选中方向的范围；把另一方向证明的下/上界丢掉没有数学必要。新实现保存这个共同交集，同时沿原方向选择规则继续细化其中一棵树。

该交集只合并上/下界，不把两种积分结果相加。四个区间的 lower 取 max、upper 取 min，均在原 strict Core 内核执行；液/总端点顺序与误差宽度约束照旧。未选分割不增加叶数，评价次数不变；树的所有 selected 非零通量叶仍必须认证原 RK2 分支。pending 候选暂用 [0,1] 的条件积分范围只在最终 selected tree 已证明全父区间有定义后才可用于成功结果，不能通过误差交集绕过 branch 守卫。

共同证书先用于更新当前父，随后沿原祖先路径与新的子和相交。即使以后子树的粗糙加法范围较宽，也保留先前 valid 证书。方向选择继续比较各候选原有指标；不引入 lookahead、采样求积或新精度/工作参数。
