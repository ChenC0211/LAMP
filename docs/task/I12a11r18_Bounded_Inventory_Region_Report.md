## 实现

4 production + 2 test-related。原 `HermiteGalsPhaseRegionSource` 在同一次区域积分中增加逐叶贡献，原标量输出及求积顺序保持。新 `HermiteGalsInventoryRegionSource` 从原 M 与同一几何测量准备两相积分权重，权重严格在 [0,1]；区域查询复用这些贡献，分别返回原几何液量、库存液量与修正诊断。没有新界面、M 重置、clipping 或接受步提交。

权重只改变库存的积分表示，不改变 scalar/first jets/normal/curvature。请求的几何—库存容限单独报告，默认仍为 `1e-10`；原/几何容量差以及整格恢复仍使用原 `64*epsilon` roundoff 门槛。非二进制坐标下的两种容量算术差也被显式覆盖。

准备权重时先完整校验 source/mesh，再通过私有 friend 批量入口复用同一求积内核，避免逐叶再次扫描完整 mesh identity。公开查询保持原身份检查，没有公开 unchecked 入口。copy/move/lifetime 与只读来源受检。
