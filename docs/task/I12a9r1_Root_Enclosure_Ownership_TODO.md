# I12a9r1 / 根包围与共享裁剪边界

## 目标：一个数学事实

横向根的数值包围尚未分辨裁剪边界，不等于真实曲线跨界。I12a9 两个 XY 算例在 accepted t=.04 后的第五步复现包围端点误拒绝；独立浅抛物线又复现包围较宽时代表点落在边界的同类问题。原失败 archive 与独立复现均保留。

## 允许与禁止修改

最多 1 production：Core/Geometry/Detail/LevelSetMappedInterface.h；最多 2 测试相关文件：独立 root-enclosure contract 与 tests/CMakeLists.txt。另含本 TODO/报告和 `runs/baselines/I12a9r1_20261001`。不改 scalar、根身份、图表划分、B/J、GL8、bubble、M、容限、冻结路径或 PDF，不修改 I12a9 driver 以绕开失败。

## 数学约束与实现

- 保持原代表点的唯一 owner 检查；真实不同区域重叠、出域和缺失 cut 必须拒绝。
- 原代表点和包围端点均具有唯一匹配 owner 的成功路径保持。未分辨时使用已有 MappedHermiteRootRefinement 对同一横向 simple root 作有界细化，重新执行原唯一归属检查；绝不直接把边界分给某个 owner。
- 仅细化内部 GL8 横向根，检查原 simple-root 导数方向不变；外部 retained face root 身份与包围不改，GL8 公式与积分次序不改。预算耗尽、真实重叠或未认证情况继续明确拒绝。生产修改前已根据复现调整最初的“仅允许闭包端点接触”方案，因为该方案不能解决代表点歧义。

## 验收

- T1：先在旧生产代码上运行独立浅抛物线裁剪反例并保留失败；跨 XY/RZ、两个 graph 方向、正反相、多个小帽高度，独立解析 Green 积分验证非零微小弧和整弧可加性。重叠/缺 cut/错误来源拒绝保持。
- 微小帽的解析比较同时记录现有 binary64 横向根误差尺度；不把 GL8 误差估计当作严格界，不要求原浮点根在任意趋零体积上仍保持固定相对精度。初始过强的纯相对比较失败日志保留。
- T2：原 I12a9 完整平移命令不变重跑，原两组 XY 第五步通过并尝试全部 40 步，记录所有后续拒绝；RZ 两组必须继续完成。完整 accepted first-jet/库存不重置。
