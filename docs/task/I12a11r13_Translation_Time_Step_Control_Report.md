## 拒绝及阶段证据

.005 配置完整 8 个 accepted end、16 个 closure，耗时 266.08 秒、退出 0。最大系数修正为 1.4865345e-3，发生在 step 3 midpoint / t=.0125 / cell 720；该时刻仍按原工作预算完成闭合。最终逐单元 M 误差为 4.3801e-6，体积总量误差约 9.0912e-12，最大 ledger 1.3878e-17、reflux 0。

.0025 配置有 10 个 accepted end、20 个成功 closure，耗时 346.91 秒、退出 1。最大系数修正为 2.3392247，发生在 step 5 midpoint / t=.01125 / cell 720；原定向区间扩展/位移证书允许该次修正。对应全局最大相对体积残差为 1.0679e-14；它不是已激活单元的工作残差单独上界，报告还包含未激活单元的 64 eps 验收残差。

随后实际 end 的曲率误差在 t=.0125 / .02 / .025 分别达到 0.6476 / 14.1700 / 21.5631。第 11 步 midpoint closure 在 cell 361 的 volume bracket 阶段因 `cell volume quadrature estimate exceeds tolerance` 拒绝，旧 accepted t=.025 保持。没有增加积分预算、缩小验证窗口或跳过拒绝继续。

这与 r12 的条件性结果相符：更细时间取样会遇到更靠近角点的小相，局部体积约束可能需要很大的内场系数响应。两次控制否定了“单纯均匀缩短步长即可解决当前例子”的判断，尚不能据此断言所有步长策略或局部空间加密均无效。
