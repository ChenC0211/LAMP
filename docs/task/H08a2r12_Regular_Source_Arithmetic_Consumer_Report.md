## 误差预算与原反例

对物理chart `p(s)=Σ c_k s^k, 0≤s≤L`，使用同一速度量纲的 `N_L(c)=Σ |c_k| L^k`。若长度单位乘α、速度单位乘β，则c_k乘β/α^k、L乘α，范数乘|β|；量纲一致的相对判定不变。原直接混加不同次数物理系数的尺度不具此性质。

原784 atom的**3,920个系数三元组逐项重现**，包括原145个raw检查失败，未改其输入或隐藏反例。新断言仍用原**1e-12**，但针对物理chart值/积分或范数误差；没有把旧阈值改大。

为避免最终系数接近零时丢掉输入运算尺度，使用有效native自由度的单位响应T_i，形成整个chart向量的列范数 `||T_i||=max_(region,chart) N_L(T_i)`，并以 `W(v)=Σ |v_i| ||T_i||` 归一化。它是可复算的**normwise线性/物理通量验收尺度**，不是逐操作舍入上界证明，也不证明准备拟合的正确性。独立解析、物理值/J、原56布局适用性及tiny相积分检查继续承担准确性验收。没有绝对floor：零work必须零残差。
