## 改变的数学事实

H08a2的J正确微分了其二次dense轨迹，但几何事件使子步时长依赖另一方向初值；局部轨迹余项经事件时间微分后可少一阶，且其系数随事件在步内的位置变化。已观察到RZ仿射源中不应出现的径向—轴向导数，以及原固定20/40/80窗口的收敛失败。这不说明任何二阶方法必然失败，却排除了只修J而保留该轨迹的做法。

本项**替换Hydro候选运动积分器**为显式三阶Ralston推进及同阶三次continuous extension。它不是原Core RK2的另一名字。现有规定速度FirstJet/Core入口保持，Hydro尚未接入它；未来耦合必须消费这一实际typed运动来源。三阶局部轨迹余项在有限个横穿事件微分后为J留出精度余量，实际阶仍由原完整矩阵裁决。

## 同一阶段、同一dense曲线

以反向elapsed e、w(e,x)=−B(t_arr−e,x)写：

```
k1=w(e,x)
k2=w(e+h/3, x+h*k1/3)
k3=w(e+2h/3, x+2h*k2/3)
k4=w(e+h/2, x+h*k3/2)        // dense扩展的辅助阶段
x_end=x+h*(k1/4+3*k3/4)
```

所有采样阶段严格位于h之前；它们必须属于同一实际分支闭包。否则只二分当前剩余区间，所有阶段重新按同一法计算；不外延或平滑B。未改变maxStep、物理窗口或来源时间律。

令θ=s/h，`P(s)=x+h*Σ b_i(θ) k_i`，固定：

```
b1 = θ − 13θ²/6 + 17θ³/12
b2 = 5θ²/2 − 5θ³/2
b3 = −θ² + 7θ³/4
b4 = 2θ²/3 − 2θ³/3
```

对每个θ：`Σb=θ, Σb*c=θ²/2, Σb*c²=θ³/3, Σb*A*c=θ³/6`，其中c=(0,1/3,2/3,1/2)，Ac=(0,0,2/9,1/3)。这些是由Taylor展开得到的三阶条件，须用精确有理数独立核验；P(h)恢复同一Ralston主步。实现用k_i−k1构造二/三次系数，避免常速项消减。

位置、elapsed及剩余h的导数逐阶段传播，不单独积分另一个variational solver。写 `P(s)=x+s*k1+s²/h*a2+s³/h²*a3`，固定s时：

```
Q=D+s*K1+s²/h*A2+s³/h²*A3−(s²/h²*a2+2s³/h³*a3)⊗H
v=∂sP=k1+2s/h*a2+3s²/h²*a3
S=−nᵀQ/(n·v), D_event=Q+v⊗S, E_event=E+S
```

固定全局时间节点；事件只切开所在区间，后续返回原节点。remaining的H=−E，二分时H同步缩放。最终固定终时补偿不能漏掉。没有独立saltation近似或平均Jacobian。

## 事件、来源及拒绝
