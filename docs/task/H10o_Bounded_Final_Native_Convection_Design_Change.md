# H10o / 最终共享 skew 对的有界求解设计

状态：实施前设计，2026-10-05；验收仍按 H10o TODO。本设计不宣称存在可行解或已通过 PDE。

## 保持的材料职责

H08/H09 只硬性保持唯一共享材料通量、内部反号及实际 AMR 子面求和、来源一致和 KEP/skew。真实三层质量与 R 原样进入动量和动能关系。Pure FirstJet 不承担守恒库存、bubble 或体积拟合。

## 求解对象和预定界

求解最终 native 矩阵的共享反对称系数 K，而非独立 trace。显式周期关系只用于符合该关系的样本；重复采样的 half-dual 质量相加后求解，其原始自由度及误差仍保留。几何 one-ring 产生固定允许边集，不能因求解失败扩大。

令 s_i 为原材料面通量绝对值之和，h_i 为真实 dual 盒最大边长，L 为几何域尺度。系数以 sqrt(s_i s_j) 缩放，行矩以 s_i 缩放。硬常数来自真实 q_i/2；光滑纯材料的一次矩目标来自 M_i B_i/h_i，B_i 为同一 actual advector 的 native 值。旧 flux-centroid 目标仅作对照，不作为点 PDE 参考。

预定有界条件保持 H10e 的物理尺度：每行 sum|K_ij| <= 2 s_i，二次移位矩 |sum K_ij (delta_a/h_i)(delta_b/h_i)| <= s_i h_i/L。与硬常数、可识别一次矩同时求解最小改动；绝不重新要求所有二次矩精确为零。该二次矩界给出二阶局部截断余项的必要尺度，不能替代全 native PDE 和时间窗验收。

先在 runs/checks 内用独立优化器核验原图可行性及残差；临时依赖不进入项目。随后实现具有明确停止判据和硬矩精化的生产求解。只保留通过验收的实现，算法收敛失败不等同数学不可行。一般 sharp-cut 目标需要按真实兼容性设计，不能借光滑纯材料可行性强制任意精确 affine。

## 实施记录：数值求解与端口边界

独立 OSQP 对原 n8/16/32 同一图给出可行近似；项目实现使用已有 Eigen 的稀疏 LDLT、ADMM 与活动约束残差精化，不引入运行依赖。常数/一次等式行的数值权重为不等式行的1000倍，ADMM参数10；该数值尺度不改变物理界。L1球按被违反的支撑半空间加入同一凸问题，不切换算子。最终按原始物理矩和界重新核验，不以 ADMM 停止残差代替验收。

显式闭合端口构建有界算子；已有不透明外部 trace 的构建契约保持，用于原非周期 affine 与一般材料短契约。后者不被宣称已经具有全部 native 有界性。该边界范围差异必须在最终报告中列明，不能因周期研究通过而隐去。
