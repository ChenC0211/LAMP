**PASS（算子验证）；I12 仍 FAIL。** 对应 [TODO](I12a11r12_Corner_Cut_Conditioning_TODO.md)。独立解析积分与原 I10 证明：小相靠近单元角点时，固定 skeleton 的 Q4 center bubble 体积灵敏度按线性 cut 尺寸的五次方退化。这里只证明局部条件性，不等同于全程稳定性结论。

## 试验与独立参考

0 production + 1 test，显式 `--corner-conditioning-control`。在 4×4 网格的 cell 5（h=.25）构造平面 phi=±((x+y−.5)/h−a)，a=2^-2,…,2^-8；小相占比 a²/2。其它单元按同一平面的解析裁剪赋 M，边界接触点明确。两个符号各 7 组，分别代表小液相和小气相。

测试内将 `u²(1-u)²(1-au)²(1-a+au)²` 独立展开为八次多项式并逐幂积分，得到归一化 dV/dc。它不使用生产求积节点或 basis helper，解析式见 TODO。与原 discovery sensitivity 的最大相对差为 6.6613e-16，低于预定 1e-9。

每组只给所选单元施加同一制造体积增量 128 eps capacity（相对值 2.8421709e-14），实际 I10 按原 active/inactive 16/64 eps、原证书及原工作量求根。该制造量不用于任何真实推进案例。M 与候选 identity 不变，8 个边界节点的 value/gradient 变化为零，center Hessian 改变量满足独立公式 −16Δc/h²。
