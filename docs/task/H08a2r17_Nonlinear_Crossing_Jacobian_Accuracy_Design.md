# H08a2r17 / 实施前积分设计

2026-10-05。前轮为 progress：r16 的可信参考区分了连续流 J 精度失败与离散 map FD 通过，100 个冻结 payload、12 份交付及原 1383 源码/输入已重新核验。[任务书](H08a2r17_Nonlinear_Crossing_Jacobian_Accuracy_TODO.md)限定本轮只修运动精度，先隔离，不同步部署正则来源。

原 Ralston-3 的阶段允许跨 C1 面，求导与自身离散 map 一致，但高阶时间导数在连接处不连续。增加未分片固定 RK 的阶数不能自动消除该误差。拟用真实分片上的 Picard 积分替代完整内部时间槽的未分片采样和：先构造二阶预测曲线，再沿它对同一实际速度积分；J 对这个实际积分公式解析求导。没有第二套场、参考值输入或守恒修复。

设回溯速度 w，槽长 h，原第一/第二阶段为 w1、w2，第二阶段位于 x+h*w1/3。取二阶曲线 `Q(theta)=x+h*w1*theta+(3/2)*h*(w2−w1)*theta²`，更新为 `x_new=x+h*integral_0^1 w(Q(theta),s+h*theta)dtheta`。Q 对全段为二阶预测，故此一次 Picard 更新为三阶。对静态 affine 场，代数上退化为同一 Ralston-3 稳定多项式，避免引入不同阶数导致原细化序列进入舍入平台。

实际 Q4 tensor 场沿二次曲线的次数至多 16，线性时间插值再加一，逐真实 support 区间使用九点 Gauss 完整积分（次数 17）。连接由实际曲线根定位，不用 cell/AMR 特例。新预测曲线的根分段仅用于积分；最终返回路径仍是原三次曲线加端点修正，重新检查其真实事件。物理/真实非 C1 命中仍按现有三次事件分支处理，其接受态没有内部积分更新；不能跨物理边界取样或把事件重启静默算作透明连接。

对积分边界 theta_e，通过根方程求 `grad theta_e=−row(grad Q,axis)/Q'_axis`。每个 Gauss 点的位置、时间、区间宽度同时求导，包含 moving-bound 的项；虽连续速度的解析边界项相消，离散求积仍必须对实际节点和权重求导。与原事件时间/剩余固定槽的敏感度合成，确保 J 来自同一离散公式。

先运行原完整候选组及两个 r16 冻结参考，记录实际工作量和 original point/J、FD、分区与时间阶。常数数值/小幅量/微小跨片也必须通过，不能仅验正常大小。若该单文件方案不能保留原事件、分区或精度要求，保留失败证据并修改设计，不通过提高容差或隐藏事件通过。生产部署和其 public API 注释同步归后续 r11，本轮原生产保持；候选数学公式在此明确记录。

实施补充：初版已关闭两个非线性 J 反例，但暴露两处独立问题。第一，原非定常 affine 检查绑定旧 Ralston 离散多项式；新的三阶 Picard 公式在非定常 affine 上不与旧公式逐字相同。仅迁移这一独立解析参考，保留原输入、1e−12 精度和完整四项 J。第二，舍入量级的端点修正可令原精确 terminal 连接偏移一个 ulp。积分均值按第一阶段作差累加，且当点修正及全 J 修正同时落在实际工作量的舍入带内时，共同保留原公式；不只保留点或只保留 J。

舍入分支以 `gamma=32*eps*(9*片段数+4)` 为操作数量余量：速度修正按新旧端点速度模定标，`h*导数修正` 按当前 map J 加新旧导数贡献定标。二者同时满足才保留原 point/J 分支，零场无速度绝对容差底线；真实非线性修正超出该带会执行。此分支不是精度 gate 的放宽，原几何/event 精确比较及 1e−11 连续流 gate 保持。细化末端可出现舍入带平台，本次报告列出全部原序列而不宣称任意小步下仍显现三阶。

独立 affine 参考推导：`a(theta)=a1+b*h*theta`，`a2=a1+b*h/3`，定义 `m=a1+b*h/2`、`q=m²/2`、`r=a1*a2*(a1/3+b*h/4)/2`。对 affine 向量场的生成矩阵 M，点/J 稳定多项式为 `I+h*m*M+h²*q*M²+h³*r*M³`；b=0 时即原静态 Ralston-3 多项式。本次测试中的 b=−2.4；它是解析时间积分结果，不从生产返回值构造。

初版源码/程序/两失败保留在 `initial_candidate`。最终实际 point-only 负控保留新点而故意不更新端点和 dense 导数，原 affine 多项式及两条原 J 精度 gate 均拒绝；不把仍通过的较松 FD gate 当成准确性充分证据。九点权重的 0–17 次矩另以 60 位 Decimal 独立核验。最终结果见[报告](H08a2r17_Nonlinear_Crossing_Jacobian_Accuracy_Report.md)。
