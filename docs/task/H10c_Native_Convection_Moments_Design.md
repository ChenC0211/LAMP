# H10c / native算子联合矩设计（实现前）

2026-10-03。按用户最新要求，最终native operator为约束对象；[H10b](H10b_Smooth_Inviscid_Benchmark_Report.md)的内部affine反例证明单段trace再现不能保证配对后的PDE再现。冻结PDF§7.2的共享材料流量、中心/低耗散结构及§6.3的局部compatible思想保持；本段明确H10a装配的必要修正，不改冻结PDF或材料路线。

## 最终系数及保持的性质

H10a内部算子为 `K_old + 0.5*diag(q_internal)`，K_old反对称；外部端口仍显式给trace。H10c在最终native pair系数上求最小改动J，要求 `J^T=−J` 和 `J*1=0`。因此 `u^T J u=0`、`1^T J u=0`，常速度不变，现有非守恒材料动量/动能预算保持。J是由已有F及几何派生的算子系数，不能解释为第二材料通量或新状态。

每个native row用其实际相邻pressure cells及一圈邻cell生成同分量支持；所有patch共享同一无向pair系数、方向相反。当前trace/位置不修改，只作为原始中心通量诊断；目标直接施加在 `N_old+J*u`。

## 内部空间矩

row i的尺度h_i取真实dual box宽度，邻点归一化偏移为 `(dx,dy)=(p_j−p_i)/h_i`。约束常数及 `{dx,dy,dx²,dx*dy,dy²}`。内部row的目标是

`(N−q*u)_i(dx/dy) = sum_g s_ig F_g*(p_g−p_i)_(x/y)/h_i`，

其中p_g为真实XY/RZ segment测度中心，同一唯一F消费一次。对局部中心二次多项式，native点处导数为0，目标为 `(N−q*u)_i(dx²/dxdy/dy²)=0`；该约束阻止AMR不对称dual平均点偏移进入点速度导数。

外部row仍施加J*1=0，其物理端口未在H10c发明；它们仍计入完整研究，不能用内部精度通过代替H10b边界/整体收敛。RZ轴本质约束仍由既有端口/研究积分器处理，原始轴载荷诊断保留。

## 小型patch约束与共享求解

未知量只是prepared过程中临时的局部pair系数改动，无新primary DOF。每个one-ring patch允许同分量支持内的共享pairs；最小化按现有局部材料率gross尺度归一化后的Euclidean改动，矩约束写成稀疏A*x=b。row尺度只来自原K与实际F，pair尺度为两row尺度的几何平均，零流量零原K的row不凭空产生修正。每个row的A块只有1或6行，由one-ring几何构成，其Gram矩阵用小型SVD核验并构造局部最小改动/预条件。

共享pair影响两row，不能一次独立修正每个patch后覆盖邻patch结果。联合求解 `(A*A^T)*lambda=b`，以局部小Gram作预条件，只通过one-ring pair执行A/A^T乘法；最终 `x=A^T*lambda`，显式复算全部矩残差。该临时约束乘子不是持久速度或高阶状态，存储/乘法为网格线性规模；不得引入dense全局operator、跨域coupling或oracle修正。

rank不足、非有限或迭代不收敛明确拒绝；不得使用旧不一致载荷fallback。新的方法性质为最终row矩一致性，而非修改trace断言。独立dense reference须同时包含原K与J；旧H10a历史数值不能再要求逐字相同，但原数值门槛不能改变。新算子可能改变谱/CFL，必须由原完整时间窗检验，不能预先宣称H10 PASS。

实现校核（2026-10-04）：原Gram显式逆在高密度比率尺度下损失局部正定性。改以同一小型A块的SVD作行白化，与原block预条件的精确数学问题相同，不改one-ring支持、最小改动目标或矩门槛。共轭迭代直接补偿累积pair解，避免末态大乘子经A^T抵消；不按固定次数重启。最后用白化前的独立系数行复算残差，拒绝规则保持。

矩误差按任务书规定的最终gross系数归一化：原行率尺度加该矩中全部J项的绝对值，避免高密度比下大项相消时将绝对舍入误差误当成相对失败。独立契约直接累加最终K+J矩，并保留原1e−12载荷/动能、1e−10常速度更新门槛；不得只用prepared报告代替实际载荷验收。

联合迭代预算为max(10,000,4*约束数)，与网格规模统一关联，无AMR分支。达到预算后仍按同一256eps矩残差决定是否可返回，不能因次数耗尽返回不合格系数。n=32准备可能触及此预算，成本和实际残差必须同时保留，不能把局部存储规模线性冒称整个准备过程线性。
