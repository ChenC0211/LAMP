状态：**PASS，2026-10-05**，见[报告](H10n_Donor_Dissipation_Gate_Contract_Report.md)。12原窗口及保存数据保持，独立能量身份/四新gate通过，四旧gate失败单列；下一唯一H10o，H10未关闭。前置 [H10m](H10m_Final_Native_Same_F_Convection_Report.md) 保留 FAIL；本项只修正与中心算子无关的 donor 对照验收定义，不开始 H11/H08a，也不声称完成最终 native 空间离散。

## 目标

明确区分有限时窗的累计能量损失与上风空间离散的 O(h) 耗散率。以独立离散能量恒等式和 Fourier 符号验证实际 donor，而不是要求进入饱和区的累计损失在既定粗网格对上呈渐近一阶。新指标的定义、阈值与历史指标的保留方式必须在实现前记录为显式设计变更；原失败结果不改判。

## 允许与禁止修改

允许既有 `cases/benchmarks/cch_convection/driver.cpp`、README、任务设计/报告及当前路线图/API 状态。预算 **0 production / 0 test / 1 research 源文件**，不新增 CMake target、工具或算例变体。临时证据只归本任务 runs/checks，关闭时冻结。

禁止改 donor 的 rhs/RK4、中心生产算子、材料 F/R/质量、几何、采样/自由度、周期配对、n8/16/32、T=1、32n 步，以及中心空间阶≥1.7、最细 L2≤0.05、Linf、动能/材料功、时间和边界条件。不得用 donor 指标修订豁免中心算子的空间问题。Pure FirstJet 独立，无库存/bubble；材料四硬约束保持。

## 数学约束与实现

1. 在原固定材料场景，独立重组实际共享内段及显式周期端口的能量耗散 `D = sum(|F|*(u_i-u_j)^2)/2`，每条周期连接只计一次，保留全部 native half-dual。证明并检查 `-sum(M*u*rhs_donor) = D`；轴条件和实际材料/边界功按原定义核验，不能省略非零项。
2. 以初始场的 `D/E(0)` 检验网格一阶耗散，保留预先的阶区间 `[0.7,1.4]`，不依据失败结果调区间。该指标直接测量半离散算子，不受 T=1 累计损失饱和影响。实际轨迹仍必须完成原时窗、呈正的可检测损失。
3. 均匀网格横向模式用独立 Fourier 符号及 RK4 稳定多项式验证逐 DOF 终值和损失；既定 n16→32 的瞬时耗散率理论阶约 0.986，累计损失阶约 0.367，两者应同时报告。
4. 原 `*_donor_loss_order` 四 gate 继续输出到独立 legacy 表并保留其 FAIL，不能覆盖历史 84-gate 结果或称原 84 gate 已通过。新版验收用明确的新指标名/版本；原其余 80 项定义逐项保持。一般中心算子通过前仍不关闭 H10。
