# 算例自述文档编写约定

每个算例至少提供 `README.md`。有正式入口时提交 `system/` 字典；尚待实现的标准问题明确标为“待接入”，不提交会采用其他模型的占位输入。按算例复杂度说明以下内容：

1. **计算目的与范围。** 属于代码验证（verification）、物理验证（validation）、工程应用或冒烟检查；可支持什么结论。
2. **控制方程与假设。** 单相/两相、平面/轴对称、黏性、重力、表面张力、电场及电荷模型，坐标和相标记约定。
3. **几何与物性。** 计算域、特征长度、单位、密度、动力黏度和表面张力；必要的 Re、We、Oh、Bo、La 及其定义，区分直径与半径标度。
4. **初始与边界条件。** 初始速度、压力和界面；逐边说明无滑移、自由滑移、轴、周期、规定通量或压力出口，以及接触线、供液口和外部相。
5. **空间与时间离散。** 网格尺寸/层级、AMR 判据和预算、界面分辨率、方法选项、步长/CFL、终时和输出间隔。静态局部加密与动态 AMR 分别说明。
6. **运行与追溯。** 从项目根目录执行的命令、字典链接、线程设置与结果位置，保留实际输入、程序身份和退出状态。
7. **观测量与判据。** 参考来源、误差范数、积分测度、压力规范和时层、质量/动量/能量收支；文献参考值与项目容差分开，没有解析解时声明网格/时间敏感性评价。
8. **状态与限制。** 未运行、运行失败、完成时窗、验收通过分别记录；图来自实际结果，旧方法结果不能充当新方法验收。

新运行保存到 `cases/<算例>/output/<时间戳_标识>/`，输入、日志、图和分析随结果保留，不放入 `build/`。失败结果同样保留。通用启动方式见[算例索引](README.md#result-layout)。
