## 参考量与本项目输出的对应

本例气泡是 `negative` 相。读取实际运行的 `output/series/hydro_moment_phase_integrals.csv`，只选择该相，每个接受端点一行：

| 参考列 | QUANTUM 字段 | 物理含义 |
| --- | --- | --- |
| 1 | `time` | 物理时间 |
| 2 | `volume_geometry`；另列 `volume_fv` | 气泡几何面积；独立有限体积库存用于守恒评价 |
| 3 | `circularity` | 等面积圆周长与实际自由界面周长之比 |
| 4 | `centroid_y` | 气泡区域内 y 的面积平均 |
| 5 | `mean_u_y` | 气泡区域内实际竖直速度的面积平均 |

平均上升速度来自真实气泡区域内完整速度场的积分，不使用质心差分、界面点速度平均或最大速度替代。几何—库存差和库存漂移须同时报告，不能只选择误差较小的一列。

## 比较范围与数据限制

三组曲线分别保留。绘图叠加三组参考，误差分别列出；不将它们平均成一条“精确解”。冻结版本时事先固定比较时刻、误差范数和通过容差。参考仅在相邻原始时刻之间线性插值到本项目的接受端点；不外推、不平滑、不为匹配极值移动时间轴。比较区间是各自数据范围与 [0,3] 的交集；三组共同对照时使用三者共同区间。

- FreeLIFE 两组从 t=0.003125 开始。MooNMD TC1 从 0.002168239 开始，TC2 从 0.004336477 开始。缺失的初段不补造零时刻数据。
- TP2D TC2 保留了 t=3 后的两行；MooNMD TC1 末行在 3.000985，TC2 延伸到 4.039896。原文件不裁剪，但本项目 T=3 以后的数据不进入本工况的误差统计；求 t=3 插值可使用包围它的两行。
- 两份 MooNMD 文件第二列全为零。本项目将这一列视为不可用于面积比较，不能据此判断气泡消失。其余三项非零物理量照常使用。
- TP2D TC1 在极早期有小幅负上升速度，原值保留。文件虽然以长科学计数格式存储，原始有效数字有限，不能把显示位数当成参考精度。
- TC1 文件在 [0,3] 的采样最大上升速度分别为 0.241696、0.24209521、0.2416576；它们不完全落入现有计划引用的论文概括范围。论文报告值与本次下载曲线分别列出，不修改文件，也不把概括范围直接设成对所有求解器都成立的硬门槛。

TC2 后期参考方法间的形状和拓扑差异仍按[主说明](../README.md)处理。完整曲线误差、采样极值及发生时间、终时值、面积守恒和分辨率敏感性分别报告。当前尚未运行本项目 TC1/TC2，未产生误差表或通过结论。

## 已接比较规则（2026-09-29；尚无计算结果）

[`tools/postprocess/analyze_hydro_standard.ps1`](../../../tools/postprocess/analyze_hydro_standard.ps1) 的 `hysingTC1/hysingTC2` 模式复用运行身份检查，读取三组原始曲线，取共同时间范围内的 QUANTUM 接受端点。每组参考只线性插值，不外推；共同范围端点若不是接受时刻，不补造一个计算状态，因此摘要报告实际采用的第一、最后比较时刻。

设这些时刻为 tᵢ，误差 eᵢ=qᵢ−qref(tᵢ)。工具以相邻实际 Δt 作梯形积分，报告 `absolute_time_RMS = sqrt(trapz(e²)/(t_last−t_first))` 和 `relative_time_L2 = sqrt(trapz(e²)/trapz(qref²))`。两者是对齐采样历程的时间范数，不宣称连续误差的严格积分；`maximum_sampled_error`、极值及其时刻同样仅指这些共同采样点。参考原文件的自身采样极值仍保留在 sources.json，不与重采样结果混用。

面积第二列全零的 MooNMD 对应项输出 `available=false` 和空值；其余三项照常比较。完整运行、失败后的接受前缀、TC2 的事件记录分开标识，不能以截短轨迹或缺失面积给出通过结论。当前只完成工具编译，具体网格/时间组及数值容差随 V 冻结后统一执行。
